# evals/

**tests는 코드 동작을, evals는 에이전트 동작을 검증한다** — 판단 품질, 도구
사용 경로, 최종 답 품질, 회귀.

구획:

- `regression/` — 반복된 에이전트 실패를 케이스로 승격하는 자리(미리 개설됨).
  **통과율 ~100%를 유지한다**. 떨어지면 그 자체가 사건이다.
- `datasets/` `rubrics/` `deterministic/` `scenarios/` `reports/` — 첫 실물 때 개설.
- `judges/` — LLM 판정자를 쓰는 평가. **개설 조건이 하나 있다**: (판정자, 용도)
  쌍마다 사람 라벨 표본으로 잰 정밀도·재현율 보정 기록을 함께 둔다. 보정 없는
  판정자는 배선하지 않는다. 판정자는 자기보다 약한 대상의 점수를 오답 상관만으로
  부풀린다는 실측이 근거다.

운용: 실패를 발견하면 최소 재현을 만들고, 코드 결함이면 `tests/regression/`,
에이전트 판단 결함이면 여기 `regression/`으로 보낸다. 분류 절차는
`skills/eval-driven-improvement/SKILL.md`가 정본이다.

실행 진입점은 `evals/run.sh`다 — 첫 케이스와 **같은 커밋에서** 만든다.
`scripts/gate_chain.sh` 6단계가 이것을 부르며, 케이스가 있는데 러너가 없으면
게이트가 실패한다(조용한 생략 금지).
