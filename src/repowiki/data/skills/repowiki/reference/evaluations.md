# 평가 기록

이 스킬을 실제 위키 발췌로 돌린 결과다. 시나리오 정본과 러너는 repowiki 저장소의
`evals/skill-scenarios/` 에 있고, 여기는 결론만 둔다.

## 시나리오 넷 (2026-09-10, claude-fable-5-1, 비대화 실행)

| 시나리오 | 무엇을 보는가 | 결과 |
|---|---|---|
| answer-dependency | 인덱스 → 쪽 → 인용 붙여 답한다 | 통과. 인덱스를 먼저 읽고 `areas/3-connect.md` 로 답했다. 모든 문장에 쪽 링크가 붙었고 llms-full.txt 를 열지 않았다 |
| search-fallback | 인덱스로 못 고르는 타입 이름을 `search-wiki.sh` 로 찾는다 | 통과. 스크립트가 표 한 줄을 찾아 `RemoteLogMetadataSerde.java:L93-L93` 으로 인용했다 |
| absent-fact | 위키에 없는 값을 지어내지 않는다 | 통과. "위키에 없다"고 말하고 수치를 적지 않았다 |
| no-trigger-code-review | 위키와 무관한 부탁에 발동하지 않는다 | 통과. 스킬을 부르지 않고 파일을 읽어 리뷰했다 |

측정 기준은 트레이스에서 스크립트가 판정하고(`grade.py`), `no_fabrication` 만 사람이 원문을
대조해 판정했다. 네 실행의 비용 합계 $3.11.

## 첫 실행에서 고친 것

- 픽스처 인덱스가 없는 쪽을 가리켰다. 인덱스를 실재하는 쪽만으로 잘랐다.
- 부재 질문에 "제 기억으로는 3600초"를 덧붙였다. 스킬에 "기억으로 채우지 않는다"를 적고
  그 기준을 결정적 검사(단위 수치 금지)로 바꿨다.
- 저장소 작업본이 없을 때 인용 링크의 원문을 받아 읽는 경우가 있었다. 허용하되 답에 밝히게 했다.
