# write-wiki

## 언제 쓰는가

`repowiki`로 저장소 하나의 위키를 만들 때. 분석부터 사이트까지 한 흐름이다.

## 두 층으로 나뉜다

**결정적 층**은 `scripts/wiki_loop.py`가 돈다. 어느 작업을 받을지, 거부된 뒤 임대를 어떻게
다시 얻을지, 언제 끝났는지, 산출물이 계획과 맞는지는 입력이 같으면 결과가 같다. 이 문서는
그것을 다시 설명하지 않는다.

**비결정적 층**은 이 문서가 다룬다. 어느 근거의 원문을 읽을지, 무엇을 쓸지, 자리표시자를
글의 어디에 둘지는 매번 다르다.

아래에서 `$L` = `<이 스킬의 base directory>/scripts/wiki_loop.py`.

## 프로세스

1. 분석과 계획을 돌린다. **종료 코드가 0이어야 한다.**

   ```sh
   repowiki run <작업본 경로> --out <산출 디렉토리>
   ```

   0이 아니면 멈춘다. 한도 위반이나 Mermaid 파서 실패는 사실 층의 결함이고, 그 위에서 쓴
   쪽은 틀린 그림을 싣는다. 사실 층을 먼저 고친다.

2. 쪽마다 이 넷을 반복한다.

   ```sh
   python3 "$L" next --out <디렉토리>
   #   → 작업을 받고 사실과 근거 목록을 함께 낸다. 종료 코드 3이면 남은 작업이 없다.

   python3 "$L" source --out <디렉토리> --job <id> --ids E1,E5,E12
   #   → 고른 근거의 원문

   # page.json 을 그 작업 디렉토리에 쓴다 (형식: reference/page-format.md)

   python3 "$L" submit --out <디렉토리> --job <id>
   #   → 통과면 0. 거부면 1이고 사유를 낸다. 임대는 다시 얻어 두므로 고쳐서 같은 명령을 낸다.
   ```

3. 전부 끝나면 묶고 띄운다.

   ```sh
   python3 "$L" finish --out <디렉토리>
   ```

## 무엇을 읽고 무엇을 쓰는가

**읽지 않은 자리를 인용하지 않는다.** `source`로 원문을 본 근거만 그 문장의 근거로 쓴다.
구조 사실만 보고 쓰면 "A가 B에 기댄다" 부류의 문장으로 닫힌다. 원문을 읽어야 그 타입이
무엇을 하는지, 무엇이 실패하는지, 어떤 판단이 코드에 남아 있는지를 쓸 수 있다.

**한 쪽에서 쓸 것은 넷이다.** 이 묶음이 무엇을 맡는가. 그 안의 것들이 서로 어떻게 일하는가.
경계면의 계약이 무엇인가. 무엇이 실패할 수 있는가. 소스 트리나 메서드 목록을 나열하는 것은
표가 이미 하는 일이다.

**형제 쪽을 건다.** `next`가 낸 "형제 페이지" 절에 경로가 있다. 링크가 없으면 위키가
그물이 아니라 목록이 된다.

**산문 규범.** 엠대시와 가운뎃점과 이모지를 쓰지 않는다. 이중 피동을 쓰지 않는다.

## 입력과 출력

- 입력: 작업본 경로.
- 출력: `<디렉토리>/wiki/`의 Markdown과 `<디렉토리>/site/out/`의 정적 사이트.

## 경고 신호 (red flags)

- `run`의 종료 코드를 안 보고 다음으로 넘어가고 있다.
- `source` 없이 쪽을 쓰고 있다. 읽지 않은 것을 말하는 것이다.
- 표나 도식을 손으로 옮겨 적고 있다. 자리표시자가 있다.
- 거부를 피하려고 문장을 늘리고 있다. 늘릴 것은 읽은 내용이지 분량이 아니다.
- `next` 대신 `repowiki job` 명령을 직접 부르고 있다. 결정적 층을 다시 짜는 것이다.

## 검증

- `finish`가 0으로 끝났는가. 쪽 수가 맞지 않으면 그것이 말한다.
- 사이트가 열리고 인용 링크가 실제로 소스로 가는가.

## 거부할 흔한 합리화

- "사실이 얇으니 일반론으로 채우겠다" — 얇은 것은 사실 층의 결함이다. 그쪽을 고친다.
- "이 도식은 이 쪽에 안 어울리니 빼겠다" — 계획 층이 준 것이다. 어울리지 않으면 계획을 고친다.
- "인용을 나중에 붙이겠다" — 문장을 쓴 뒤 근거를 찾으면 근거가 문장에 맞춰진다.
- "이번만 직접 명령을 부르겠다" — 그 판단이 임시 스크립트를 낳는다.

## 이 스킬이 싣는 것

```
write-wiki/
  SKILL.md
  scripts/wiki_loop.py         # 결정적 층: 받기, 원문, 제출과 재임대, 마무리, 문턱 값
  reference/page-format.md     # 제출물의 형식과 게이트 규칙 (필요할 때 읽는다)
```
